# AA制分账计算器

一个简单易用的AA制分账计算工具，支持多种分账场景。

## 功能特点

- **简单模式**：快速计算总金额的人均分摊
- **多笔消费**：支持多笔消费记录的汇总分账
- **已付款模式**：计算其他人应付给垫付者的金额

## 本地运行

直接用浏览器打开 `index.html` 文件即可使用。

或者启动本地服务器：
```bash
python -m http.server 8000
```

然后访问 http://localhost:8000

## 部署

本项目为纯静态页面，可部署到任何静态托管服务，如 GitHub Pages、Netlify、Vercel 等。
